CubeSat Attitude Control Flight Software

C++17fixed-pointARM Cortex-M3custom RTOSWebAssemblyQEMU

Flight software that keeps a small satellite pointed where it's told. It detumbles the spacecraft, fuses gyro and sun-sensor data, slews with a rate-limited anti-windup PID, detects frozen or lying sensors and drops into SAFE mode, and dumps reaction-wheel momentum with magnetorquers. All in Q16.16 fixed point for an FPU-less Cortex-M3, running as a task on my own RTOS. The same C++ compiles to a 5 KB WebAssembly module, so the live demo runs the real flight code: kick the satellite or break its sensors and watch it recover.

3.5 sdetumble from 8°/s
0.14°overshoot on a 90° slew
0.52 sto detect a sensor fault
0.04°final pointing error

Cortex-M3 RTOS from Scratch

C++17ARM assemblyCortex-M3QEMUCI

A preemptive real-time kernel with no vendor libraries, C runtime, or heap: priority scheduling with time slicing, PendSV context switching in assembly, semaphores with timeouts, and a type-safe message queue. Startup code, linker script, and UART driver written by hand. Fits in 2.8 KB; CI boots it in QEMU on every push.

Bare-Metal Two-Board Rock-Paper-Scissors

C++AVR ATmega328PUARTI2Cinterrupts

Two microcontrollers play each other over a serial link. Register-level UART, timer, and I2C LCD drivers with no Arduino libraries, and a fault-tolerant protocol with CRC-8, parser resynchronization, and a lock-before-reveal handshake so neither board can peek. The live demo lets you add line noise and watch it recover.
